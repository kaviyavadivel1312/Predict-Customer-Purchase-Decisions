# Predict Customer Purchase Decisions for an Online Retail Company

## Project Objective
To predict whether a customer will purchase a product from an online retail company using machine learning techniques.

## Dataset Description
The dataset contains 2,000 sample customer records and 10 columns, including age, gender, annual income, website browsing time, pages viewed, previous purchases, cart items, discount usage, device type, and purchase decision.

**Target variable:** `Purchased` (0 = No, 1 = Yes).

*Note: The dataset is synthetically generated for educational purposes.*

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Methodology
1. Load and explore the dataset.
2. Check missing values and data types.
3. Encode categorical variables.
4. Split data into training and testing sets.
5. Train a Random Forest Classifier.
6. Predict customer purchase decisions.
7. Evaluate the model using accuracy, precision, recall, and F1-score.
8. Visualize the confusion matrix.
9. Identify important features influencing model predictions.
10. Save the trained machine learning model.

## Expected Results
- Customer purchase predictions.
- Purchase probability estimates.
- Model evaluation metrics.
- Confusion matrix visualization.
- Feature importance analysis.

## Conclusion
This project demonstrates how machine learning can be used to analyze online customer behavior and predict purchase decisions. The approach can support customer behavior analysis and help online retailers investigate factors associated with purchase conversion. Real-world performance must be validated using genuine customer data.
